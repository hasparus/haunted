# 3D hand

Current rig: **`SparrowHawk/RightHandRigging.unity`**.

Saved standby/grabbing poses drive the in-game claw. The runtime hand is enlarged to fit normal-sized thought orbs; the manual posing scene remains unchanged. **Match Game Camera** in the Inspector resets the view without moving the rig.

See `SparrowHawk/README.md` for animation, sizing and tests; `SparrowHawk/CREDITS.txt` for the CC0 license. Final stylization remains unfinished.
