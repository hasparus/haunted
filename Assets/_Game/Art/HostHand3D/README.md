# 3D hand

Open **`SparrowHawk/RightHandRigging.unity`** for the current right-hand rig.

Standby and grabbing poses are shown side by side, with a game-size thought orb. Select a hand object and click **Match Game Camera** in the Inspector to reset the view without changing the pose.

See `SparrowHawk/README.md` for controls and `SparrowHawk/CREDITS.txt` for the CC0 model license. Gameplay attachment and final stylization remain unfinished.
